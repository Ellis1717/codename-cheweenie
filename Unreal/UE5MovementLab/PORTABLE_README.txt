Codename .... Cheweenie — Windows core adventure 0.13.1

Double-click PLAY_GAME.cmd to start. Keep the entire Windows folder beside it.
Choose Play / continue adventure to explore the house and neighbourhood.

Move: WASD or the left stick. Look: mouse/right stick.
Interact: E / Xbox X / PlayStation Square. Jump: Space / Y / Triangle.
Pause: Escape / Menu / Options. Camera: V / right-stick press.
Use the in-game Controls guide for tricks, pet actions and current bindings.
Pause > Controls > Screen overlays lets you hide individual gameplay overlays.

This release includes clearer brick/mortar surfaces, the close-up coat update and saved overlay controls.
Earlier versions stay available through the local archive catalog, when supplied.
The portable ZIP excludes the owner's private map, saved progress and archive paths.
Physical controller handling and separate-PC LAN require human checks.
