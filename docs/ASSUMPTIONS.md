# Editable assumptions and decisions

Unreal Marty 0.7: standard controls remain default. The optional Tricks → Controls mode interprets the requested two joysticks as left-stick actor-relative movement plus right-stick spring lean/turning (12° roll, 8° pitch; less when tired), with automatic settling and following camera. It uses CharacterMovement collision/gravity, not a free ragdoll. Live: toggle using C or B/Circle. Code/build: DogBodyControls.cpp tunes spring/damping/limits. Walking/jogging/running use 100/155/230 cm/s, with 70 when tired; these are game speeds rather than measured biomechanics.

Health is a gentle future-facing damage/recovery meter, initially 100, with no added combat hazards. Zero returns Marty safely home at 25 health. Food restores 20 health/30 energy; resting restores health slowly. The backpack has four slots but the current map has two toys. Lie/roll/shake are procedural skinned poses; action views briefly use an obstruction-tested side camera. Health, energy, bag contents, pace and control mode persist; transient poses/spring offsets reset. Code/build: DogLife.cpp and DogTricks.cpp.

The detailed coat is original inferred geometry guided by the retained Marty photos and cover: short tan fur, darker ears, cream chest, dark eyes and checker collar. It remains stylized rather than a photographic reconstruction. 16,000 skin-weighted polygon hairs and 4K maps balance detail against this machine's memory limit; they are not a Groom simulation. Original smooth/static assets and previous packages remain available. See UNREAL_MARTY_07.md for retained sources, rollback flags and actual tests. Physical controller feel and subjective likeness are owner checks.

Unreal pet sandbox 0.6: energy/moods are gentle game mechanics, with tired walking always available. Three marked shallow dig patches retain the collision floor. One carried toy and one item per hole; carried/buried IDs and energy persist, while loose toys reset to safe spawn spots on reload. The couch hop uses physics with a delayed forward assist; TV uses an original silent ball animation and a fixed watch camera. Food is available in a schematic kitchen corner and refills on a short cooldown. See UNREAL_DOG_LIFE.md for controls, tuning and save rules.

Unreal exterior 0.5: reuse the retained local OSM street file; do not trace or publish a Google Maps screenshot. The house's red brick, blue garage/door and bay-window features follow the private reference, with inferred dimensions. Eight stationary neighbour-dog/house slots are placeholders until names are supplied. LocalGameData holds private layout and labels outside public assets. E/X-Square uses doors, greets dogs and uses optional tour boards; H returns indoors. Neighbour friendship is saved by stable slot. See UNREAL_NEIGHBOURHOOD.md.

Unreal Marty art: the start-page Cover.png is the owner's explicit visual target. The new cover-guided model uses smooth skin weighting and procedural canine IK, with a short-coat material rather than a strand groom. Ear base/tip movement and leg joints are prioritized for visible motion. The fourth camera is a close inspection view. Cats remain on their existing meshes for this focused Marty milestone. See UNREAL_MARTY_ART.md for editable sources and tuning.
